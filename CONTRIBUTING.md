# Contributing to fishbowl

Thanks for looking under the hood! fishbowl is intentionally small —
read the design principles before sending changes.

## Design principles (the deal-breakers)

1. **Read-only.** fishbowl never writes to the transcript source. Anything
   that mutates `~/.claude` (or any watched root) is out of scope.
2. **Stdlib only** (Python 3.10+) on the backend, **zero dependencies** on
   the frontend (no frameworks, no CDN, no external links). If your change
   needs `pip install`, discuss it in an issue first.
3. **Loopback only.** The HTTP server stays bound to `127.0.0.1`, hard-coded.
   Remote access / multi-user / auth features belong to a future supervised
   distribution, not this repo.
4. **Fail soft.** A malformed transcript line, a 6 MB attachment line, an
   empty file — none of these may crash or stall the scanner.
5. **Small.** Prefer deleting code over adding it.

## The one hard rule

**This repository never contains real transcripts.**

`~/.claude/projects/` holds your actual source code, prompts and secrets.
Never copy a real session file into the repo, into an issue, into a
screenshot, or into a test. All fixtures are generated by
[fishbowl/fixtures_gen.py](fishbowl/fixtures_gen.py) — synthetic paths, synthetic
branches, scripted numbers. If you need a new scenario, add it there with a
seeded RNG so it stays deterministic.

## Development setup

```bash
git clone <your fork>
cd fishbowl
python -m unittest discover -s tests -v
python -m fishbowl --demo --port 8799    # poke at the UI
```

No virtualenv needed (no dependencies); use any Python ≥ 3.10.

## Code layout

| Path | What |
|---|---|
| `fishbowl/parser.py` | line JSON → domain objects, pure functions |
| `fishbowl/scanner.py` | incremental scanning, byte-offset cursors |
| `fishbowl/store.py` | in-memory session index, bounded activity rings |
| `fishbowl/status.py` | active / idle / stalled / archived classification |
| `fishbowl/adapter.py`, `claude_code.py` | source discovery protocol + implementation |
| `fishbowl/server.py`, `api.py` | loopback HTTP server, read-only GET API |
| `web/` (inside the package) | zero-dependency single-page dashboard |
| `fishbowl/fixtures_gen.py` | seeded synthetic transcript generator |

## Testing

- All new parser/scanner/store logic needs unit tests against generated
  fixtures — never against a real `~/.claude`.
- Status logic takes an injected clock; do not use `sleep()` in tests.
- Keep the suite green: `python -m unittest discover -s tests`.

## Pull requests

- Small, focused PRs beat large ones.
- New user-visible strings: English, plain.
- New CLI flags or API routes: update README and tests together.
- You agree your contributions are MIT-licensed.

## Reporting bugs

Include: OS, Python version, how you launched fishbowl, and — if relevant —
a *synthetic* reproduction (extend the generator). Do **not** paste raw
transcript lines; trim to structure if needed.
